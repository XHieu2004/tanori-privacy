1. Tiếng Việt — Chính sách bảo mật của Tanori

Tanori là ứng dụng đọc sách cá nhân, hỗ trợ chuyển ngữ và nghe đọc ngoại tuyến trên Windows do K.Shadow phát hành. Chính sách này giải thích cách ứng dụng xử lý dữ liệu và kết nối mạng trên máy của bạn.

1.1. Dữ liệu lưu trữ hoàn toàn cục bộ trên máy

  • Toàn bộ tệp sách bạn nhập (EPUB, PDF, TXT, ZIP), bản dịch, ghi chú, Sổ tay nhân vật/thuật ngữ, tiến độ đọc/nghe và tùy chọn hiển thị được lưu trực tiếp trong thư mục dữ liệu người dùng tại %LOCALAPPDATA%\TanpopoAI\Tanori.
  • Nhà phát hành không vận hành máy chủ lưu trữ thư viện, không thu thập dữ liệu phân tích (telemetry), không gắn trình theo dõi (tracking) và không yêu cầu đăng nhập tài khoản để sử dụng ứng dụng.

1.2. Khóa API của nhà cung cấp AI (BYOK)

  • Các tính năng dịch AI và tạo giọng đọc Cloud (tùy chọn) sử dụng mô hình BYOK (Bring Your Own Key): bạn tự nhập khóa API hoặc tệp thông tin xác thực từ nhà cung cấp bạn chọn (Google AI Studio / Gemini, Google Cloud Vertex AI, OpenAI, DeepSeek hoặc endpoint tương thích OpenAI).
  • Khóa API được mã hóa cục bộ bằng chuẩn bảo mật Windows DPAPI trước khi lưu trên máy tính của bạn và không bao giờ được gửi về nhà phát hành.
  • Khi bạn chủ động khởi chạy tác vụ dịch hoặc nghe giọng Cloud, nội dung đoạn văn bản liên quan và thông tin xác thực của bạn được gửi trực tiếp từ máy của bạn tới API của nhà cung cấp bạn đã cấu hình, tuân theo chính sách bảo mật và điều khoản của nhà cung cấp đó.

1.3. Tải model giọng đọc ngoại tuyến (Offline ONNX)

  • Bạn có thể nghe đọc miễn phí bằng giọng nói có sẵn của Windows mà không cần tải thêm dữ liệu.
  • Nếu bạn chủ động bấm tải một model Offline ONNX (VieNeu-TTS v3 Turbo, Supertonic 3, Kokoro-82M v1.1-zh, Qwen3-TTS 1.7B), ứng dụng kết nối qua HTTPS trực tiếp tới kho lưu trữ công khai trên Hugging Face để tải các tệp trọng số và kiểm tra toàn vẹn SHA-256. Sau khi tải xong, model chạy hoàn toàn ngoại tuyến trong thư mục bạn chỉ định.

1.4. Quyền ứng dụng Windows

  • internetClient: chỉ dùng khi bạn kết nối khóa API AI cá nhân (BYOK) hoặc chủ động tải model giọng đọc ONNX; kết nối nội bộ giữa giao diện và máy chủ cục bộ chỉ diễn ra trên địa chỉ loopback 127.0.0.1.
  • runFullTrust: cần thiết để đóng gói runtime desktop Windows (Python + WebView2), đọc tệp sách bạn chọn, mã hóa khóa API qua Windows DPAPI và cho phép chọn thư mục lưu model trên ổ đĩa cục bộ.

1.5. Xóa dữ liệu và liên hệ

Bạn có toàn quyền xóa từng quyển sách, bản dịch, khóa API hoặc xóa hoàn toàn thư mục %LOCALAPPDATA%\TanpopoAI\Tanori và thư mục model tự chọn bất kỳ lúc nào. Nếu có câu hỏi về quyền riêng tư, vui lòng liên hệ nhà phát hành K.Shadow qua trang ứng dụng Tanori trên Microsoft Store (Store ID: 9MWBXMW29NVC).

2. English — Tanori Privacy Policy

Tanori is a personal book reader, AI literary translation studio, and offline text-to-speech application for Windows published by K.Shadow. This Privacy Policy describes how Tanori handles data and network requests on your device.

2.1. Local-Only Data Storage

  • All imported books (EPUB, PDF, TXT, ZIP), translations, reading notes, Story Notebook glossaries, reading/listening progress, and preferences are stored exclusively on your PC inside %LOCALAPPDATA%\TanpopoAI\Tanori.
  • The publisher does not operate any cloud account server, does not collect telemetry or usage analytics, and does not require sign-in to use Tanori.

2.2. Bring Your Own AI Credentials (BYOK)

  • Optional AI translation and cloud speech features follow a strict Bring Your Own Key (BYOK) model using credentials you provide directly (Google AI Studio / Gemini, Google Cloud Vertex AI, OpenAI, DeepSeek, or OpenAI-compatible endpoints).
  • Saved API keys are encrypted locally on your Windows account using Windows DPAPI and are never transmitted to or stored by the publisher.
  • When you initiate a cloud translation or cloud speech request, relevant text snippets are sent directly from your computer to the provider endpoint you configured, subject to that provider's own privacy terms.

2.3. Optional Offline ONNX Speech Downloads

  • You can use built-in Windows system voices offline at any time without downloading extra files.
  • If you explicitly choose to download an optional offline ONNX voice package (VieNeu-TTS v3 Turbo, Supertonic 3, Kokoro-82M v1.1-zh, Qwen3-TTS 1.7B), Tanori downloads model weight files directly from Hugging Face repositories over HTTPS with SHA-256 verification. Once downloaded, inference runs completely offline in your chosen folder.

2.4. Windows Package Capabilities

  • internetClient: used solely for user-initiated BYOK provider calls and optional Hugging Face speech model downloads. Embedded UI-to-backend communication stays strictly on loopback 127.0.0.1.
  • runFullTrust: required for the packaged Windows desktop runtime (Python + WebView2), opening user-selected ebook/document files, encrypting API credentials via Windows DPAPI, and storing optional model weights in a user-chosen local folder.

2.5. Data Control & Contact

You may delete any book, translation, or stored API key inside Tanori at any time, or remove %LOCALAPPDATA%\TanpopoAI\Tanori and any chosen model folder directly from Windows. For privacy questions, contact publisher K.Shadow via the Tanori listing on the Microsoft Store (Store ID: 9MWBXMW29NVC).
